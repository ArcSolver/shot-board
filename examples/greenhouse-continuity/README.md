# The greenhouse

A traveler discovers a small brass compass in a rain-soaked greenhouse.

02 Medium holds eight Qwen-Image-2512 takes rendered in the app. The hero, T06, shows the traveler holding a brass compass with N, E, S and W, a fine tick ring, a red and silver needle and a glass cover. Qwen-Image-Edit-2511 redrew the other five cuts from it with Render reference edits.
